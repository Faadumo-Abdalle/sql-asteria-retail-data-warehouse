# Asteria Retail Data Warehouse

A data engineering project demonstrating SQL, relational database design, and business analysis using a fictional online retailer.

## Project objectives
-	Design a relational database
-	Create tables with primary and foreign keys
-	Populate realistic retail data
-	Answer business questions using SQL

## Tools used
-	**SQL**
-	**GitHub**
-	**Draw.io (ERD)**
-	**Microsoft SQL Server**
